# 📋 Controle de Refeições — React Native App

> Aplicativo mobile para registro e acompanhamento de refeições diárias, auxiliando no controle de dieta e hábitos alimentares.

---

## 📱 Sobre o Projeto

O **Controle de Refeições** é um aplicativo mobile desenvolvido com React Native que permite ao usuário cadastrar, visualizar, editar e excluir refeições, além de acompanhar se está dentro ou fora da dieta e visualizar seu progresso diário.

O objetivo do projeto é praticar conceitos fundamentais de desenvolvimento mobile como navegação, persistência de dados, gerenciamento de estado e componentização.

## ⚙️ Pré-requisitos
 
Antes de rodar o projeto, certifique-se de ter instalado:
 
- [Node.js](https://nodejs.org/) (versão LTS recomendada)
- [npm](https://www.npmjs.com/) ou [yarn](https://yarnpkg.com/)
- [Expo CLI](https://docs.expo.dev/get-started/installation/)
- [Expo Go](https://expo.dev/client) no seu celular (opcional, para testar no dispositivo físico)
---
 
## 🛠️ Como Rodar o Projeto
 
### 1. Clone o repositório
 
```bash
git clone https://github.com/WendellOliveiraDeveloper/OrcamentosReactNative.git
cd OrcamentosReactNative
```
 
### 2. Instale as dependências
 
```bash
npm install
```
 
### 3. Inicie o projeto
 
```bash
# Inicia o servidor Expo (QR Code para Expo Go)
npm start
 
# Ou escolha a plataforma diretamente:
npm run android   # Android (emulador ou dispositivo)
npm run ios       # iOS (somente macOS)
npm run web       # Navegador web
```

## 🧭 Navegação
 
O projeto utiliza o **React Navigation** com suporte a:
 
- `@react-navigation/native` — Integração base
- `@react-navigation/native-stack` — Navegação em pilha nativa (performática)
- `@react-navigation/stack` — Navegação em pilha com animações customizáveis
